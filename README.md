# Weather App 🌦️

A simple weather app I built using HTML, CSS, and JavaScript. You can search for a city and get its current weather information, including temperature, humidity, wind speed, and weather conditions.

I used the Open-Meteo API to fetch the weather data and JavaScript to handle the search and update the page based on the results.

## Features

- Search for a city to check its weather
- Display temperature, humidity, and wind speed
- Show weather conditions with different icons
- Handle invalid city names
- Search using the Enter key or the search button

## Built With

- HTML
- CSS
- JavaScript
- [Open-Meteo API](https://open-meteo.com/)

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Search for a city and check the weather.
